## Overview

This PR implements a chat history API for sending conversation data to the MCP (Model Context Protocol) platform for real-time threat protection. The implementation follows the .NET SDK version from PR #148 in the Agent365-dotnet repository.

**Key Changes:**
- Added `OperationError` and `OperationResult` classes to the runtime package for consistent error handling
- Created `ChatHistoryMessage` and `ChatMessageRequest` model classes in the tooling package
- Implemented `send_chat_history()` method in `McpToolServerConfigurationService`
- Added comprehensive unit tests (39 total tests)
- Updated copyright headers to the correct format
- Added `microsoft-agents-hosting-core` as a dependency

**Overall Assessment:** The implementation is solid with good test coverage and proper error handling. However, there are several issues that should be addressed before merging, ranging from validation logic concerns to missing type hints and potential security considerations.

**Description:**
The validation in `ChatHistoryMessage.__post_init__()` uses truthiness checks (`if not self.id:`) which rejects empty strings but accepts whitespace-only strings like `"   "`. This is inconsistent with the project standard shown in `McpToolServerConfigurationService._validate_server_strings()` which uses `.strip()` to check for meaningful content. **Diff Context:**

```diff
+            raise ValueError("timestamp cannot be None")
```

**Suggestion:**
Use explicit `.strip()` checks for string validation to ensure consistency with the rest of the codebase:

```python
def __post_init__(self):
    """Validate the message after initialization."""
    if not self.id or not self.id.strip():
        raise ValueError("id cannot be empty")
    if not self.role or not self.role.strip():
        raise ValueError("role cannot be empty")
    if not self.content or not self.content.strip():
        raise ValueError("content cannot be empty")

        raise ValueError("timestamp cannot be None")
```
